# Enhanced-Adversarial-Learning-for-Low-Dose-Brain-PET-Denoising
Enhanced Adversarial Learning for Low-Dose Brain PET Denoising

Low-dose (LD) positron emission tomography (PET) imaging is essential for reducing radiation exposure but suffers from severe noise and artifacts that compromise diagnostic quality. This study introduces a novel conditional generative adversarial network (cGAN) framework, termed Enhanced Loss-Pix2Pix, incorporating a novel three-component loss function combining adversarial, L1, and structural similarity index measure (SSIM) losses to preserve both pixel accuracy and perceptual quality. The framework features architectural refinements, including a compact 6-encoder/5-decoder U-Net generator with InstanceNorm2d, strategic normalization omission, selective dropout regularization (p=0.5), Xavier initialization (σ=0.02), and gradient clipping for training stability. A comprehensive evaluation on datasets from the University of Bern and Shanghai Ruijin Hospital across multiple dose levels (1%, 2%, 5%, 10%, 25%, 50%) demonstrates exceptional performance. At an ultra-low 1% dose, the framework achieves a peak signal-to-noise ratio (PSNR) of 33.61±3.23 dB (Bern) and 37.35±3.32 dB (Shanghai), an SSIM exceeding 0.973, and a normalized root mean squared error (NRMSE) of 0.024-0.025, significantly outperforming state-of-the-art methods by 8-14 dB PSNR while maintaining 25% lower NRMSE. At 50% dose, PSNR reaches 46.25±4.07 dB (Bern) and 50.06±2.52 dB (Shanghai) with SSIM approaching 0.997. These results validate Enhanced Loss-Pix2Pix as a clinically viable solution for substantial radiation dose reduction while preserving diagnostic image quality.
